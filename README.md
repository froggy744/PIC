# PIC — Picasa iPhoto Clone

A photo manager with folder and network browsing, libraries, editing, collages and themes.

[GitHub repository](https://github.com/froggy744/PIC) · [Documentation and user guides](docs/README.md)

Build on Linux from the repository root:

```sh
./scripts/PIC-build-linux-one-script.sh local
```

See the [Linux build guide](docs/build/linux.md) and [portable NFS guide](docs/build/portable-nfs.md).
