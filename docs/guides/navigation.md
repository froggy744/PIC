# PIC Guide 1 — Navigation

*Part of the [PIC user guides](../README.md).*

## The window

<img src="../../Screenshots/All%20Photos.jpg" alt="PIC window with sidebar, search, photos and bottom information bar" width="900">

- **Sidebar:** Library destinations, Albums, Folders and Network Shares.
- **Top bar:** search, sorting, grouping, rating filtering and application controls.
- **Photo area:** the current collection as a grid, folder sections or Photo Wall.
- **Bottom bar:** selected-photo information, actions, the layout toggle and shared zoom slider.

The Library section includes **All Photos, Favourites, Recently Added and History**. Its heading opens the library overview. Albums are virtual collections; folders and shares reflect the locations you imported.

## Select and open

Click a thumbnail to select it. The bottom bar shows available metadata such as filename, date, camera, dimensions and size. Double-click, or press Enter or Space, to open the selected photo. Right-click a photo for actions such as Edit, Favourite, Add to album, Open in Folder, Export and Print; available actions depend on context.

Use arrow keys to move through thumbnails and **Ctrl + click** for multiple selection. **Ctrl+A** selects the current scope; in Folder view that is the active folder. **Ctrl+D** clears the selection.

## Grid, Photo Wall and zoom

The bottom bar's view toggle switches to **Photo Wall**, which fits photos into rows using their natural proportions. Use the zoom slider or **Ctrl + wheel** to resize thumbnails.

<img src="../../Screenshots/Photo%20Wall%20Screen.jpg" alt="Photo Wall layout with the sidebar visible" width="900">

The shared slider adapts to the viewer and editor when they are active. It is disabled in contexts such as collage editing where that zoom control does not apply.

## The photo viewer

- **Left / Right or mouse wheel:** previous or next photo in the collection you opened.
- **Space or the 1:1 control:** toggle fit and native-size inspection.
- **Zoom slider, + / − or Ctrl + wheel:** zoom in or out.
- **Click and drag:** pan when the photo is zoomed in.
- **Esc or double-click:** close the viewer and return to the selection.
- **F11:** toggle full-screen window mode.

A cached preview can appear first, followed by a higher-quality decode. Native image data is loaded when close inspection needs it. The window can show a viewer without being in full-screen mode.

<img src="../../Screenshots/Rations%20Stars.jpg" alt="Viewer displaying a portrait and its star rating control" width="900">

The number keys **1–5 assign ratings**, and **0 clears a rating**. Use Space or the 1:1 control for magnification. Shortcuts avoid text fields so typing does not rate or open photos.

## Search and history

Search photo and folder names from the top bar. Use the suggestion list to choose a folder and **Enter** to open it; PIC clears the search and navigates to that folder. **Esc** clears search text. History collects recently edited photos and recorded editing operations.

Sorting includes date taken, name, file size, dimensions, date added and rating. Grouping by Day or Month is available in library views; Folder view supplies its own folder sections.

## More space for photos

Use the sidebar toggle to hide or reveal the sidebar. Hover behavior and other interface preferences are available in Settings.
