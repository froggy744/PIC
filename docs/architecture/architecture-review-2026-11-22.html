Problem. Six sidebar modes are written by 24 widget-visibility calls in three files. There have been 65 sidebar, compact or immersive commits since October, and layout.rs has 0 tests.

Solution. One module owns the mode flags and computes one target state. It is the only thing that writes those widgets.

  • Locality: mode bugs live in one module
  • Transition tables as plain tests
  • Interface shrinks from an 18-tuple to events
Large move (~1-1.5k lines), and animation timing sits nearby. Stage it so the state is extracted before any writer changes.

Problem. "Is it open?" depends on a global context and widget visibility. Immersive mode bypasses close_properties and only works because a global happens to stay set.

Solution. One module instance owns allowed, open, suspended and scroll position per surface, and pushes the result to the split, the panel and the InfoBar button.

Status (2026-11-23)

Candidate 1 is done and merged into main: grid/presentation.rs (commits 0df3b918, afa6d54a, a3a71299, 62dff881).

Candidate 2 is done and merged into main (merge commit 03a2fcb3): a pure state machine window/sidebar_presentation.rs, which also owns the pin, and one GTK adapter window/sidebar_widgets.rs that every sidebar writer dispatches to. All 16 sidebar display tests pass on a 1920x1080 Xvfb display, and hover peek, pin, narrow/wide window, divider drag and Immersive Mode were checked by hand.

Candidate 3 is done and merged into main (merge commit 2da69bae): a pure state machine window/properties_presentation.rs and one GTK adapter window/properties_widgets.rs, the only writer of inspector visibility and the InfoBar button. The 13 inspector thread-locals and the Immersive guards are gone; Immersive Mode suspends the panels instead of hiding them behind a guard, so a selection change in Immersive Mode no longer starts a hidden open/close transition.

Candidates 4-8 are open.

Top recommendation

Deepen gallery thumbnail presentation

This is where the most recent bugs came from, and every one of them was a leak between modules. Three gallery surfaces make the seam real, the existing display tests guard the behaviour, and AUDIT-INDEX.md already maps it. Runner-up: Sidebar presentation, which has the most churn but carries more risk; start it once candidate 1 has proved the pattern.
