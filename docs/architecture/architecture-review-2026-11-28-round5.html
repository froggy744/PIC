Problem. "A drag is one undo step" is written five times. Only the sliders in controls.rs survive GtkScale cancelling the release, and the Draw sliders add one undo step per tick, so one drag can push the rest of the history off the 100-step limit.

Solution. A Continuous edit module owns the gesture-to-undo rule. The panels bind a value to it.

  • Leverage: one interface, five panels
  • Tests without a display
  • Lost release can't leak edits
  • Delete four dragging cells
