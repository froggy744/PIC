# PIC V1.01 — Your photos. Your folders. Your way.

This draft covers the changes and fixes merged after V1.0.0 through commit `0b63584`. The [complete commit-by-commit comparison](https://github.com/froggy744/PIC/compare/V1.0.0...v1.0.1) includes the full 342-commit range.

## Library, metadata and ratings

- Expanded the Metadata/Filters panel with source-folder and orientation filters, improved metadata column choices, sorting and filter controls, and clearer, more compact filter presentation.
- Added a Rating metadata column and a separate Ratings sidebar collection, with a setting to show or hide that collection.
- Refined sidebar sections, action icons, History controls, and behaviour when panels are collapsed or automatically hidden.
- Improved the library index and album browsing experience, including album navigation and cover presentation.

![V1.01 Metadata and Filters panel](https://raw.githubusercontent.com/froggy744/PIC/main/screenshots/v1.01/metadata-panel.jpg)

## Albums and screensaver

- Added reflective Bookshelf and Cover Flow album layouts to the screensaver, with follow-up fixes to cover flow quality and navigation.
- Redesigned Bookshelf presentation with responsive shelf density and cover sizing; kept covers aligned and stable through resizing, avoided empty rows, and refined collapsed Albums headings and dividers.
- Improved album layout themes, cover selection, spacing, and rendering.

![V1.01 Albums Cover Flow screenshot](https://raw.githubusercontent.com/froggy744/PIC/main/screenshots/v1.01/screensaver-coverflow.jpg)

## Editing and RAW photos

- Added a live OpenGL editor renderer for supported hardware, including zoom, crop, straighten, rotation, creative effects, and image/text overlays. PIC checks capabilities and falls back to CPU rendering for unsupported hardware, recipes, or renderer errors. Export remains on its established CPU path.
- Improved Nikon NEF handling: embedded JPEGs remain the fast Fit/browsing path while full-resolution viewing, editing, and export use the sensor-derived RAW renderer; the previous rendering path remains available as a fallback.
- Added shared Filter Amount control for Auto Enhance, Auto Contrast, Auto Colour, and Auto Brightness. Fixed Auto Brightness colour clipping and excessive shadow/noise lift, and made filter amount resets predictable and undoable.
- Improved rendering parity and regressions around GPU crop/geometry, overlays, filters, metadata, and image orientation.

## Export, packaging and reliability fixes

- Continued export fixes for orientation, colour profiles, metadata privacy, transparency, overlays, collision handling, and atomic non-overwriting saves.
- Fixed AppImage SVG cache creation under concurrent launches, smoke-test startup and diagnostics, packaging test ordering, and GitHub release publishing scripts. Updated package metadata and the release build workflow for V1.01.
